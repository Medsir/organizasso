# Organiz'asso

*Projet d'implémentation d'un site web dans le cadre d'un projet universitaire*

## Concept

Le projet consiste en un site web de forum permettant à des membres d'une association de pouvoir échanger des messages.
Deux forums sont proposés :
  - Le forum Public ouvert à chaque membre inscrit
  - Le forum Privé reservé aux administrateurs de l'association

### Inscription

Un utilisateur non connecté aura la possibilité de créer un compte, pour se faire il devra entrer certaines informations 
et attendre la confirmation d'inscription de la part d'un administrateur faite manuellement.

## Implémentation : La Stack

- JavaScript (ReactJS)

### Côté serveur
- NodeJS
- ExpressJS

### Communication Client/Serveur
- ReactJS (axios)

### Base de données
